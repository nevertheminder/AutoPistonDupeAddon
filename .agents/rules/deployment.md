# Deployment Rule
When building the `AutoPistonDupeAddon`, always do the following:
1. Delete any old `autopistondupe-*.jar` versions from these three directories:
   - `D:\Games\Minecraft\сборки\tbt2 1.21.4 forge\minecraft\mods`
   - `D:\Games\Minecraft\сборки\6b6t_2\minecraft\mods`
   - `D:\Games\Minecraft\сборки\6b6t_3\minecraft\mods`
2. Copy the newly built `.jar` file (from `build\libs\`) into all three of those directories.
